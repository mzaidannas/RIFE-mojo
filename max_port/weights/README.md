# RIFE v4.25 weights for the MAX Graph port (Phase P3)

Generated by `max_port/extract_weights.py` from `train_log/flownet.pkl`.

- **Output file:** `rife_v4_25.safetensors` (~22.67 MB, 158 tensors, 5,664,776 params)
- **dtype:** all tensors are `float32`.
- **Source:** loaded like `Model.load_model(rank=-1)` — `torch.load(..., map_location="cpu")`
  then the `module.` prefix stripped from every key. (Every key in the checkpoint
  carries the `module.` prefix; all 198 were kept by the strip.)

## Naming scheme (output key)

The output keys mirror the PyTorch module tree, with the parameter-less
`Sequential` indices (LeakyReLU / PixelShuffle) collapsed away so a graph builder
can index layers directly:

| Submodule | Output keys |
|-----------|-------------|
| Head (source `encode`) | `head.cnn0.{weight,bias}`, `head.cnn1.*`, `head.cnn2.*`, `head.cnn3.*` |
| Block `i` (0–4) first downsample conv | `block{i}.conv0.0.{weight,bias}` |
| Block `i` second downsample conv | `block{i}.conv0.1.{weight,bias}` |
| Block `i` ResConv `j` (0–7) | `block{i}.convblock.{j}.conv.{weight,bias}`, `block{i}.convblock.{j}.beta` |
| Block `i` lastconv (ConvTranspose) | `block{i}.lastconv.{weight,bias}` |

Source → output key remapping:

- `encode.*` → `head.*`
- `...conv0.0.0...` → `...conv0.0...` and `...conv0.1.0...` → `...conv0.1...`
  (the middle `.0` is the `Conv2d` inside each `conv()` = `Sequential(Conv2d, LeakyReLU)`)
- `...lastconv.0...` → `...lastconv...` (drops the `PixelShuffle` sibling index)
- `convblock.{j}.conv`, `.beta`, and all `.bias` keys keep their natural names.

The mapping is strictly 1:1 — every mapped source key produces exactly one output
tensor and there are no output-key collisions.

## Layout transforms (pinned in MOJO_MIGRATION_PLAN.md §1b)

| Kind | Which keys | Transform | Result shape |
|------|-----------|-----------|--------------|
| `nn.Conv2d` weight | `head.cnn0/1/2`, `block*.conv0.0/0.1`, `block*.convblock.*.conv` | torch OIHW `.permute(2,3,1,0)` | `(kh, kw, Cin, Cout)` (RSCF, for `ops.conv2d`) |
| `nn.ConvTranspose2d` weight | `head.cnn3`, `block*.lastconv` | torch IOHW `.permute(2,3,1,0)` | `(kh, kw, Cout, Cin)` (for `ops.conv2d_transpose`) |
| bias | all `*.bias` | unchanged | `(Cout,)` |
| `beta` | `block*.convblock.*.beta` | unchanged | `(1, c, 1, 1)` |

Note: Conv2d and ConvTranspose2d use the **same** `permute(2,3,1,0)`, but because
the torch source layouts differ (OIHW vs IOHW) the resulting semantics differ.
For `ops.conv2d_transpose`, bias must be added manually over the NHWC channel axis
in the graph (§1b) — it is stored here as a plain `(Cout,)` vector.

Inverse (for verification): `max_tensor.permute(3,2,0,1)` recovers the original
torch weight exactly.

## Deliberately skipped keys (40, not on the inference path)

With `fastmode=True, ensemble=False` (the inference config in `IFNet.forward`),
the `teacher` and `caltime` submodules are never executed, so their weights are
excluded:

- `teacher.*` — 30 keys (an `IFBlock`: `conv0`, 8× `convblock`, `lastconv`)
- `caltime.*` — 10 keys (5 conv layers `caltime.0/2/4/6/8`)

No other keys are skipped; there are zero unexpected orphans.
